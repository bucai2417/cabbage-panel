# 在线体验 Demo

`docs/` 根目录下的 `index.html`、`app.js`、`styles.css`、`logo.png` 是一个**纯前端**的可交互演示，不依赖后端、不发起任何网络请求，所有数据都在浏览器内存里。

## 打开方式

任选一种：

1. 直接双击 `docs/index.html`（`file://` 可直接运行）。
2. 本地起一个静态服务器：

```bash
cd docs
python -m http.server 8765
```

然后访问 <http://127.0.0.1:8765/>。

3. 部署到 GitHub Pages 时，把仓库 Pages 源设为 `docs/` 目录即可；部署到其他静态托管时，上传 `docs/` 下的 `index.html`、`app.js`、`styles.css`、`logo.png` 四个文件。

## 能体验什么

| 页面 | 可交互内容 |
| --- | --- |
| 仪表盘 | 统计卡片、执行趋势曲线、完成率环形图、最近运行列表、运行环境资源监控（CPU / 内存 / 磁盘 + 运行时检测）、查看日志 |
| 定时任务 | 新建 / 编辑 / 删除任务、运行与停止、启停开关、置顶、状态筛选（含计数）、搜索、按列排序、分页、多选批量操作、任务详情、查看源码 |
| 环境变量 | 添加 / 编辑 / 删除、显示与隐藏变量值、复制、启停开关、置顶、上移下移、按状态筛选、搜索、按列排序、分页、多选批量启停与删除 |
| 脚本管理 | 目录树展开折叠、搜索、多选、新建文件 / 文件夹、重命名 / 移动 / 复制 / 删除、下载、历史版本、编辑器行号同步与未保存标记、全屏编辑、Ctrl+S 保存 |
| 运行日志 | 运行记录列表、打开日志弹窗、运行中实时状态 |
| 订阅管理 | 添加 / 编辑 / 删除订阅、启停开关、立即同步（模拟进度）、同步日志、多选批量同步与启停 |
| 依赖管理 | Node.js / Python / 系统包分类、添加 / 编辑 / 卸载、重新安装（模拟进度）、安装日志、多选批量操作 |
| 接口文档 | 开放 API / 内置 API 双 Tab、分组导航、接口展开详情、参数与请求体、复制 cURL、搜索、全部展开 / 折叠 |
| 系统设置 | 常规 / 告警 / 备份 / 账户 / 关于五个子页 |

通用交互：

- 左侧导航切换页面，自动生成标签页
- 标签可关闭、关闭其他、关闭全部；标签列表保存在 localStorage
- 页面切换保留滚动位置
- `Ctrl/Cmd + K` 聚焦全局搜索
- 侧边栏「定时任务」旁显示运行中任务数量徽章
- 移动端（≤760px）侧边栏变为抽屉，工具栏自适应

## 与真实面板的区别

- 不执行任何脚本、不读写文件、不连接数据库
- 所有「运行 / 同步 / 安装 / 保存」都是前端模拟，刷新页面即恢复初始数据
- 数据全部是通用示例（`demo/backup.py`、`DEMO_TOKEN` 等），不含任何真实任务、脚本、变量或仓库地址
- 接口文档页的路径、参数和响应结构对齐项目真实 API，但只做展示，不会真正发送请求

## 文件结构

```
docs/
├── index.html   演示页面骨架
├── styles.css   完整视觉样式（含响应式与 WCAG AA 对比度）
├── app.js       全部交互逻辑（无依赖、无构建）
├── logo.png     面板图标（同时用作 favicon 与侧栏品牌图）
└── README.md    本说明
```

## 维护

- 修改 `app.js` 中的 `navItems`、`tasks`、`apiGroups` 等常量即可调整演示数据。
- 视觉规范与正式前端保持一致（绿色主色、圆角卡片、柔和阴影）。
- 改动后建议在桌面（1440px）和移动端（390px）各看一遍，确认无横向溢出。
