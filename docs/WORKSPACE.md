# v1.1 工作区使用指南

## 脚本与文件夹

脚本管理显示含空文件夹的目录树。可展开/折叠全部、搜索路径、多选当前可见文件。每行右侧的菜单支持新建子项、下载、重命名、移动、复制和删除。脚本管理只负责直接运行，不提供创建定时任务的入口；定时任务在「定时任务」页面新建并填写命令。批量选择父目录与其子项时，后端只处理父目录一次。

移动/复制先选择目标目录；目标存在时拒绝覆盖，并逐项报告结果。移动或重命名直接使用 task、python/python3、node、bash/sh 的任务时，会同步更新命令中的脚本路径并保留参数和编辑历史。包含复合 Shell 命令且引用待移动路径的任务会阻止移动，需要先手动调整命令。运行或排队期间禁止移动、重命名、删除脚本树，避免任务读到过时路径。

目录条目上限 10000；一次目录操作最多 10000 项 / 512 MB。不进入 .git、node_modules、__pycache__；不跟随符号链接。UTF-8 文本编辑上限 4 MB。配置页的 system.json 和 notifications.json 是系统设置的视图，不能删除或改名。

## 编辑器

| 操作 | 快捷键 / 入口 |
| --- | --- |
| 增加 / 取消四空格缩进 | Tab / Shift+Tab，支持多行选择 |
| 撤销 | Ctrl+Z / macOS Cmd+Z |
| 重做 | Ctrl+Shift+Z 或 Ctrl+Y / macOS Cmd+Shift+Z |
| 保存 | Ctrl+S / Cmd+S |
| 查找 / 替换 | Ctrl+F / Cmd+F 打开查找栏，Ctrl+H 打开替换；支持区分大小写、整词、正则、上一个/下一个和全部替换 |
| 补全 | Ctrl+Space 或「代码补全」按钮 |
| 跳转行 | 工具栏「跳转行」 |
| 折叠代码块 | 行号右侧折叠箭头 |
| 自动换行 | 工具栏开关 |
| 历史预览 / 恢复 | 编辑器右上角历史按钮 |

Python、JavaScript、JSON、Shell 有语法高亮。补全来源为语言关键字、常用函数、代码片段和当前文档符号；JSON 有语法错误提示。没有后台语言服务器，不提供 Python 第三方库完整类型推导或跨文件语义检查。

每次缩进是独立撤销步骤。Tab / Shift+Tab 只在代码编辑区缩进；查找栏内 Tab 保持普通焦点切换。切换文件、页面、配置页签、关闭全屏任务编辑器时，未保存修改会用面板内确认弹窗拦截；直接关闭浏览器标签页时使用浏览器原生提示，因为浏览器不允许自定义该提示。点击任务名称打开页内任务详情；详情中的「源码」进入全屏编辑器，「编辑任务」修改调度参数。任务列表中点击 `task xx` 命令区域可直接打开源码编辑。复杂命令无法自动定位源码时，可手动选择文件，不会改写原命令。

## 任务详情

点击任务名称进入页内任务详情，不再通过多层弹窗查看。首屏把任务概览和执行概览并排展示：任务状态、Cron、命令、上次/下次运行，以及成功率、成功/失败、平均耗时和最近运行。底部嵌入实时日志，可切换最近运行、筛选日志行、跟随输出和下载完整日志，日志终端最高 500px 并在区域内滚动。详情中的「源码」才进入全屏源码编辑器，「编辑任务」修改调度参数。

## 脚本调试

脚本管理打开文件后，点击工具栏「调试」进入全屏工作区：左侧代码、右侧实时日志。修改后的代码无需保存即可点击「运行当前代码」，面板会把当前内容写入临时文件执行，任务结束后自动清理；运行中可点击「停止运行」终止脚本。若运行失败，错误会以红色提示显示在日志区，并在对应代码行显示红色标记。顶部提供「保存」「环境变量」和「关闭」；环境变量以弹窗形式管理，支持搜索、新增、编辑、启停和删除。关闭调试时，如果左侧内容未保存会先确认；退出后不会把这些调试修改带回脚本编辑器，脚本编辑器保持打开调试前的状态。

## 内置配置

| 配置 | 作用 |
| --- | --- |
| system.json | 全局并发、默认超时、日志保留天数、GitHub 更新仓库；与系统设置同步 |
| notifications.json | 通知失败开关和通知渠道数组；与通知表单同步 |
| config.sh | 在任务 Shell 中加载，变量自动导出给脚本进程 |
| task_before.sh | 任务执行前加载；返回非零退出码会阻止本次任务 |
| task_after.sh | 主任务结束后加载；CABBAGE_EXIT_CODE 是主任务退出码 |

三个物理 Shell 文件仅在首次缺失时初始化，不覆盖现有内容。普通任务命令在子 Shell 中运行，退出码传给后置钩子，后置钩子不会修改原始任务状态。强制停止/超时会清理进程树，不保证后置钩子能完成。系统 JSON 在 SQLite 事务中保存；备份包含这些设置，恢复后立即生效。

## 通知

脚本管理 → 配置文件 → 通知配置，或系统设置 → 通知，使用同一个配置。可添加多个渠道、启停、编辑后「保存并测试」。每个渠道独立报告服务是否接受请求；没有启用渠道时会提示。只有已启用渠道接收面板失败/超时通知和脚本主动通知。失败通知开关不阻止脚本主动发送。

| 渠道 | 配置字段 | 青龙常见对应字段 |
| --- | --- | --- |
| 企业微信机器人 | 完整 URL 或 Key | QYWX_KEY |
| 钉钉机器人 | Token、可选签名密钥 | DD_BOT_TOKEN、DD_BOT_SECRET |
| 飞书机器人 | 完整 URL 或 Key、可选签名密钥 | FSKEY、FSSECRET |
| Bark | 设备码，或含设备码的完整 URL | BARK_PUSH |
| Telegram | Bot Token、Chat ID，可选 API 主机 | TG_BOT_TOKEN、TG_USER_ID、TG_API_HOST |
| PushPlus | Token | PUSH_PLUS_TOKEN |
| Server酱 SCT | SendKey | PUSH_KEY |
| 通用 Webhook | URL | WEBHOOK_URL |

通用 Webhook 使用 POST JSON，字段包含 title、message、content、msgtype 和 text.content。各专用渠道使用对应协议，HTTP 200 但业务错误也会显示失败。单个请求超时 10 秒，最多 16 个渠道并发发送。SCT 与 sctp/Turbo 不是同一地址格式；Turbo 必须填写完整发送 URL。

字段对应表用于迁移参考。面板不会执行或自动解析任意青龙 config.sh 中的通知凭证；通知表单/notifications.json 是内置通知的配置来源。自带通知库的脚本仍可通过环境变量或 config.sh 读取其原有字段。

面板将通知助手安装在 data/bin，通过 PYTHONPATH/NODE_PATH/PATH 注入任务，无需额外 pip/npm 包：

Python：

    from notify import send
    send("任务完成", "中文内容")

JavaScript（CommonJS）：

    const { sendNotify } = require('sendNotify')
    sendNotify('任务完成', '中文内容').catch(console.error)

可在 async 函数中使用 await 等待发送结果。ESM 可使用 createRequire(import.meta.url) 加载该助手。Shell：

    notify '任务完成' '中文内容'

助手通过与面板相同的 HTTP 端口发送，凭证每次启动随机生成，只允许发通知，无法读取配置或操作任务。助手只适用于面板启动的任务；已有同名脚本模块可能优先被其本地导入路径选中。

实现时核对了青龙官方项目的 sample/config.sample.sh 和 sample/notify.py 中的通知字段、协议与签名规则：

- https://github.com/whyour/qinglong/blob/develop/sample/config.sample.sh
- https://github.com/whyour/qinglong/blob/develop/sample/notify.py

## 日志和列表

运行日志页先按任务名称归组，显示最近状态、运行次数、成功率和最近运行时间；点击任务进入第二层，左侧选择运行记录，右侧直接查看该次日志，不再继续弹窗。日志弹窗支持选择最近 500 次运行，不再固定展示最后一次。运行日志页展示最近 1000 条记录，可搜索、分页、多选删除已结束的记录。预览显示末尾 2 MB，下载完整日志保留该次执行已保存的全部输出（执行日志上限 20 MB）。选中文字使用独立前景色与背景色；复制不会包含页面按钮。

环境变量、订阅、依赖都有多选、分页和批量操作。任务支持批量运行、停止、启停、置顶/取消置顶与删除。选择当前页不会清除其他页已选择的记录。环境变量列表默认显示变量值并支持一键复制，名称右侧显示 #ID 标识，同时展示最后修改时间。

列表默认按创建时间排序：任务按启用状态分组，启用任务在上、禁用任务单独排在下方；组内置顶任务优先，其余按创建时间新到旧。环境变量按创建顺序排列，新建变量放在末尾，支持置顶、上移/下移，以及全部 / 已启用 / 已停用 / 已置顶筛选。订阅、依赖、开放应用和备份默认按创建时间新到旧。

删除任务、脚本、变量、订阅、依赖、日志、开放应用和备份前会显示统一确认弹窗，列出将受影响的项目并区分危险与提示级别。取消后不会产生任何改动；确认按钮只在用户主动点击后执行，弹窗打开时按 Esc 等同于取消。

## 系统设置与安全

设置页左侧导航在页面滚动时保持悬浮固定，方便切换设置分组。开放应用以卡片列表展示，应用可以设置有效期；到期后不能换取或使用 Authorization。Client ID / Client Secret 用于标识应用，Client Secret 会保存在本地数据库，管理员可在应用行点击「查看密钥」随时查看或复制，不需要重置；旧版本创建且未保存明文密钥的应用需重置一次。MCP / API 实际访问使用单独的 Authorization（Bearer），可在应用列表的「创建 Authorization」中设置 1 小时到 30 天的有效期，或勾选永久有效。MCP 服务区域不再要求 Client ID / Secret，只需选择一个带 mcp 权限且未过期的应用，再选择 Authorization 有效期（包含永久）并生成令牌。令牌会登记在应用中，刷新页面后会在「已有 Authorization」中选择并重新显示，可复制或撤销；永久令牌不会自动过期，但应用本身到期后仍会失效。

设置页「登录日志」只展示登录记录，字段与青龙 `GET /api/user/login-log` 一致：登录时间、登录地址、登录 IP、登录设备和登录状态（成功/失败），最多保留最近 100 条。本机与内网地址标注为「内网IP」。反向代理部署时，如果直连地址是本机或内网，会优先读取 X-Forwarded-For / X-Real-IP。
