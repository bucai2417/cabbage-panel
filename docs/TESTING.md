## 复现

    npm --prefix web ci
    npm --prefix web run build
    go test ./... -count=1 -timeout 180s
    go vet ./...
    go test -race ./... -count=1 -timeout 180s
    npm --prefix web run test:e2e

只改前端且测试程序已支持 `--web` 时，可设置 `CABBAGE_TEST_WEB_DIR=web/dist` 后再运行 Playwright，测试会从磁盘读取最新前端，只需 npm 构建，不必重编译 Go。

Windows 的竞态检测需要 C 编译器。有些 MinGW 编译器不能处理中文临时路径；将 GOTMPDIR、TEMP、TMP 指向英文路径再执行，例如 D:/cabbage-panel-build-cache/tmp。正式 CGO_ENABLED=0 构建无此限制。

浏览器测试使用独立临时目录与端口 15700，测试截图保存到 test-results/，不打入发行包。
